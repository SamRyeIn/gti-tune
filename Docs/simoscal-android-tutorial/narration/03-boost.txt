Boost is the visual editor for all five switch-patch map slots. Choose a slot with the chips at the top. The selected curve is active; the other four remain visible for comparison. Drag a point for a quick adjustment, tap a point for exact entry, or use the breakpoint stepper to move through the twelve RPM positions. Choose the nudge size, then use plus and minus for repeatable changes.

The graph shows two limits that mean different things. The solid IP_PUT_SP — Pressure up throttle setpoint full-load ceiling is what the ECU uses at each RPM. A slot above that line has no effect there, so the app shades that capped region. The higher dashed refusal line is the engine's hard write boundary. Dragging is approximate, so it clamps into the legal range. A typed number is explicit intent, so an illegal value is refused instead of silently changed.

Use Overlay a log to draw actual boost and the ECU setpoint from a SimosTools pull behind the calibration curves. This is useful for comparing what you asked for with what the car delivered. Flat cap sets the active curve to one value. Copy from duplicates another slot. Smooth removes sharp local steps. The shared RPM-axis editor affects every slot, so use it deliberately. Like Tables, Boost is staged: review the whole draft, then Apply once, or Discard. Switching slots while a draft is dirty is refused so an edit cannot vanish unnoticed.
